# LingoMatch 第二轮全库教学质量审计

日期：2026-10-18（北京时间）。阶段：**仅审计，未修改代码、词库、录音、课程逻辑，未构建或同步 Xcode。**

## 结论

上一轮“释义更贴近目标词”不代表完整教学链已经正确。当前同时存在图词错配、自然表达质量、反向释义遗漏三类问题。应先修明确教错的项目，不应把所有地区差异、泛称或图符文化表达一律重命名。

本轮记录 **124 条审计记录，涉及 101 个不同 Emoji ID**：66 条已确认文本问题、39 条疑似／需母语复核、18 条地区差异或可保留、1 条重点语音待复听。记录数不等于错误单词数：同一 ID 可分学习词和不同母语方向多条；可保留项不算错误。

已确认文本问题中：P0 17 条、P1 48 条、P2 1 条。P0 是本任务定义的“明确教错”，不是程序崩溃等级。

“已确认文本问题”指当前取值、明显语法／拼写或不等义关系可确定，**不代表已经七语母语者独立审校，也不代表对应录音发音错误**。自然度、精细物种或地区习惯证据不充分的判断单列为疑似。

## 本轮最重要的非 P0 观察

- 有些“前一轮已经修过”的方向只是部分修正。例如 Snowboarder 的英语→中文已正确，其它三门目标词→中文仍把人译成滑雪板。必须按实际课程方向验收，而不是只按 Emoji ID 算完成。
- 母语释义仍有照搬独立图符标签的残留：法语把河豚写成翻车鱼、韩语把夹具写成压缩机、中文把日式灯笼写成御手玉等。
- 动作与人物、物体存在系统性混淆：Fencing／Juggling 是动作，但不同课程反复在“击剑”和“击剑的人”、“杂耍”和“杂耍者”之间切换。
- 不是所有上位概念都要改。草食恐龙、三角紫菜包饭、日式团子／米糕串等可以有本土化表达；只要图能合理承载、释义忠实，不应强制四语一字对应。
- 不应一次性把人物词中的女性全去掉，或所有中性英语都加女性。已正确的 Factory Worker 与女性の溶接工可以并存；用户此前人工确认了日语包含女性，但这不等于本轮重新认证整段发音。

## 全局音频回退风险（另计，不塞入单词错误统计）

P1、代码逻辑确认但未真机复现：src/lib/wordSpeech.ts 的 pickEnglishVoice 在没有目标语言系统声音时会回退英语声音；speak 随后使用这个声音的 lang。若某次录音启动失败、进入 TTS 回退，日／韩／西语可能由不匹配语言的系统声音朗读。文件存在并不能排除这个条件。

复现前提：录音不可播＋设备没有目标语言声音。验收必须在实际 iOS 设备验证，不能声称现在用户听到的所有录音都受此影响。这里只记录风险，未改逻辑。

## 建议的确认顺序（未实施）

1. 先确认 P0 中确实需要换学习词的项目；学习词换了才配套重录，不能只改字或凭 ASR 自动替换。
2. 将纯母语释义错误单独批准，保持正确目标词和已有录音。
3. 把缺冠词、明显拼写问题等 P1 集中交母语审校确认最终短词，之后再给精确 TTS 清单。
4. 保留地区差异清单，明确地区定位；不要无差别“统一” Shortcake、독수리、三角紫菜包饭等。
5. 完成重点人工听审后，再扩展到全库录音。听审记录必须绑定实际文件 SHA-256；不能只说某个文件名以前听过。
