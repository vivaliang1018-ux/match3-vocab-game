- 逐项阅读一轮 1,117 个 Emoji 词条的四门实际学习表达，并检查七种母语名称之间的语义差异。

- 按母语计：中文 525、英文 337、西语 404、日语 432、韩语 441、法语 596、德语 611。

## 修正原则

翻译当前课程里实际显示的学习表达，不能把另一种语言的 Emoji 名称直接当成对应翻译。语法性别不必机械写成「男性/女性」；词义明确限定人物性别时则保留。

| 实际学习表达 | 母语释义举例 | 原因 |
|---|---|---|
| 日语 女性の溶接工 | 中文 女焊工；法语 soudeuse；德语 Schweißerin | 此表达明确是女性焊工 |
| 英语 Factory Worker | 中文 工厂工人；日语 工場作業員；韩语 공장 노동자 | 英语词本身没有限定女性或焊接职业 |
| 日语 ザリガニ | 中文 淡水螯虾；德语 Flusskrebs | 不是海产龙虾 |
| 英语 Lobster | 日语 ロブスター | 不能直接使用同一 Emoji 的日语名称 ザリガニ |
| 日语 大変よくできました | 中文 做得非常好！ | 翻译日语表扬语，而不是照搬英文 White Flower |

规则入口在 `src/lib/courseWord.ts`；语义数据位于 `src/data/courseSemanticGlosses.ts`、`courseGlossTranslations.ts`、`englishCourseGlosses.ts`、`courseReverseGlosses.ts` 和 `courseGlossOverrides.ts`。

## 仍应单独复核，不冒充全部认证完成

本次是语义初审与结构回归，不等于七种语言均经母语审校，也不等于重新人工听过全部录音。此前 ASR 不明确的录音仍然不明确；依据可读目标词修正翻译，不能用来证明录音正确。

下列原始学习词存在地区用法、泛称或命名质量问题，未擅自改学习词和对应音频：

- 韩语 너구리：正式动物分类与口语中对浣熊的叫法存在差异，需结合教学目标明确物种。
- 韩语 독수리：正式分类与日常「鹰」的泛称存在差异，需确认希望教授的物种层级。
- 英语 Shortcake：英语地区与日韩常见草莓奶油蛋糕用法并不完全相同；当前保留蛋糕方向释义，应确认具体课程采用的地区语义。
- 英语 Cinema Light、Japanese Symbol：原学习词本身不够明确；仅改母语翻译不能彻底解决命名问题。若调整目标词，需要另行核对并更新对应录音。
- 英语 Mermaid 的 ASR 输出不可靠；当前中文「美人鱼」不因性别关键词启发式未命中而判为错译，录音仍需人工判断。

这些项目不阻止结构测试通过，但不能将测试通过解读为词库已获得语言学或语音的完整认证。
