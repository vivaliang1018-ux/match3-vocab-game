## 仓库外凭证目录建议

为每类素材建立一个文件夹，并保留以下内容：

1. `01-account-plan.png`：生成当天的套餐或付款记录，遮住完整卡号。
2. `02-work-page.png`：作品页面、作品 ID、生成日期和使用账号。
3. `03-terms.pdf`：生成当天有效的官方商业使用条款。
4. `04-input-note.txt`：是否使用参考图、真人声音、品牌角色或现成作品。
5. `05-file-map.txt`：证据对应到 App 内哪些文件。

不要把含账号、订单或付款隐私的凭证提交到公开 GitHub 仓库。

## 判定规则

- 只有免费套餐：检查生成当日条款是否明确允许商业发布；不明确则重做或购买覆盖该作品的授权。
- 使用了品牌角色、真人、现成插画或受版权保护作品作为提示图：必须另行确认权利，平台生成许可不能替代第三方权利。
- 保存原始生成记录与条款版本；App Review 或投诉处理时可快速出示。
