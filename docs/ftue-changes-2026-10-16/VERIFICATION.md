# FTUE 四项调整：实施与验证

日期：2026-10-16。仅实施用户确认的四项；未提交代码、未上传或发布 App。

## 已实施

1. **Quiz**：删除 Skip Quiz 及放弃确认，无替代退出按钮。保留六词选图/配对小测、答错重试。按课程和游客/账号保存题序、选项、已答题、配对结果、错误记录及完成标记；每次有效作答立即写入，不等待发音/动画。重新打开 App 时，待做 Quiz 自动恢复，不需先点首页开始，也不重新扣体力。全部六题完成才调用原有结算；结算后删除检查点，旧组件不能重新写回已结算的小测。
2. **课程**：首页课程选择确认直接进入所选课程，保留原有必要条款环节，不再回首页多点一次 Start。
3. **通知卡**：Next 无条件继续，包括第二次展示和通知开启请求尚未完成时。卡片保留 Remind me、Not now、光晕及原有授权范围；略过第二次邀请后记录延期，不自动打开通知。
4. **Say & Blast**：进入后先介绍玩法及麦克风/语音识别用途；用户点 Start Practice / Start Game 后才检查、申请权限。首次授权成功接入慢速练习，已完成教学用户接入正式游戏。未监听时不再显示 Listening。
