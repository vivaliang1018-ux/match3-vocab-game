# LingoMatch 人物词汇性别与释义审查

审查日期：2026-10-16。仅审查与提出文字修正建议，未修改产品词库、录音或进度。

## 范围与结论

扫描全库 1,117 条词条，交叉检查英文／中文与西语、日语、韩语、法语、德语实际返回名称。扩大性别标记、人物 Emoji 和职业词形检查后，101 条进入人工核对，其中 87 条进入按课程修正／进一步细分清单，14 条暂不因性别差异修改。此数量是词条数，不是错误译文数，也不是需要重录的数量。初筛的 85 条只是关键词候选，不能当作最终错误数。

当前目标语言为英语、西语、日语、韩语；法语与德语是可选母语，其词形也影响释义准确度。

## 修正原则

1. 保留学习词与现有录音，只修正对应母语释义；本次没有执行修改。
2. 释义由 sourceLanguage + targetLanguage + item.id 决定，不能全局替换英文 word 或中文 cn。例如英学日 guard 应解释为 Female guard，但英学西的 guardia 不应被强行加 female。
3. 职业阴阳性可以是正常语法；检查的是母语释义是否充分表达当前学习词，不把正常女性词形判成翻译错误。
4. 学英语时目标词 Teacher 不含女性，即使插图是女性，母语释义也不能机械沿用“女性教师”。双向课程均需核对。
5. 这是一份文字数据审查，未逐条试听音频，不能据此证明现有录音完全一致。
